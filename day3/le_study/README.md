This repository contains three Jupyter notebooks that demonstrate how AI can be used to simulate, detect, and predict the evolution of light echoes.


Notebooks


- [unet.ipynb](unet.ipynb) — Mapping Light Echoes with U-Net

Train a U-Net model to segment light echoes from astronomical images.


- [LEsim.ipynb](LEsim.ipynb) — Simulating Light Echoes

Generate a sequence of simulated light echo images.

- [lstm.ipynb](lstm.ipynb) — Learning Light Echo Evolution with ConvLSTM

Train a U-Net + ConvLSTM model to predict future light echo images from a sequence of previous observations.

dataset is available [here](https://drive.google.com/drive/folders/1MRg4-S1YsDIhT94E-8V5Kw6ZgQNbbd5E?usp=sharing)
